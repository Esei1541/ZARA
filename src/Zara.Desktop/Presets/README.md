# 긴급 해제 문장 프리셋

이 폴더의 텍스트 파일은 긴급 해제 문장으로 사용할 후보를 작품별로 100개씩 담는다. 각 파일은 UTF-8 형식이며, 한 줄이 하나의 문장이다. 문장 앞에 번호나 주석을 넣지 않는다.

## 출처

- `gwangyeom-sonata.txt`: 김동인, 「광염 소나타」. 사용자가 제공한 `김동인-광염_소나타-중외일보.txt`에서 선별.
- `readymade-life.txt`: 채만식, 「레디메이드 인생」. 사용자가 제공한 `채만식-레디메이드_인생-신동아.txt`에서 선별.
- `wings.txt`: 김해경, 「날개」. 사용자가 제공한 `김해경-날개-조광.txt`에서 선별.

사용자가 이 세 원문을 자유롭게 이용할 수 있는 만료 저작물로 제공했다. 원문 파일은 저장소에 포함하지 않는다.

## 선별 기준

- 줄바꿈과 탭은 공백 한 칸으로 바꾸고, 앞뒤 공백을 제거한다.
- 한글, 숫자, 공백, 마침표, 쉼표, 느낌표, 물음표만 허용한다.
- 공백을 포함한 길이는 20자 이상 90자 이하다.
- 한글 글자는 12자 이상이어야 한다.
- 문장 끝은 마침표, 느낌표, 물음표 중 하나여야 한다.
- 마침표, 느낌표, 물음표가 연달아 반복되는 문장은 제외한다.
- 작품 안에서 같은 문장이 반복되면 하나만 남긴다.
- 제목, 주석성 문장, 지나치게 짧거나 문장으로 완결되지 않은 조각은 제외한다.
- 원문에 있는 특수문자, 한자, 영어가 포함된 문장은 고쳐 쓰지 않고 제외한다.

후보는 작품 전체에서 치우치지 않도록 원문 순서에 따라 고르게 선택했다. 이 파일의 문장은 화면에 표시한 문자열과 정확히 일치하는 입력만 통과시키는 용도로 사용한다.
