## 개요

ZARA는 정해 둔 시간에 컴퓨터 사용을 멈추고 잠자리에 들 수 있도록 돕는 Windows 프로그램입니다.

요일마다 사용을 멈출 시간과 다시 사용할 시간을 정하면, 그 시간 동안 컴퓨터 화면을 잠급니다. 급한 일이 생기면 **긴급 해제**로 잠시 사용할 수 있고, 늦게까지 컴퓨터를 써야 하는 날에는 **시간 외 사용 예약**을 미리 등록할 수 있습니다.

## 설치법

Windows 11용 64비트 설치 파일을 사용합니다.

설치 시 관리자 권한이 필요합니다.

1. [최신 배포 페이지](https://github.com/Esei1541/ZARA/releases/latest)를 엽니다.
2. 첨부 파일 목록에서 `ZARA-버전-win-x64-Setup.exe`를 다운로드 합니다.
3. 안내에 따라 설치를 진행합니다.

## 주요 기능 및 사용법

### 요일별 자동 잠금

월요일부터 일요일까지 잠금 시간을 각각 정할 수 있습니다. 설정한 시간이 되면 모든 모니터에 잠금 화면이 나타나고, 해제 시간이 되면 다시 사용할 수 있습니다.

1. **사용 금지 시각**을 엽니다.
2. 잠금을 적용할 요일의 **사용**을 체크합니다.
3. **시작 시각**과 **해제 시각**을 입력합니다.
4. **설정 저장**을 누릅니다.

해제 시각을 시작 시각보다 이르게 설정하면, 자정(밤 12시)을 지나 **다음 날 해당 시각에 해제**됩니다. 예를 들어 오후 11시에 시작해 오전 7시에 해제하도록 설정하면, 그날 밤부터 다음 날 아침까지 잠깁니다.

- 시작 시각과 해제 시각을 같게 설정할 수는 없습니다.
- 특정 요일의 잠금을 끄려면 해당 요일의 **사용** 체크를 해제하고 저장합니다.
- 평소에는 기본 화면에서 다음 잠금까지 남은 시간을 확인할 수 있습니다.

### 긴급 해제

잠긴 상태에서 컴퓨터를 잠시 써야 할 때 사용합니다. 화면에 나온 문장을 직접 입력하면 정해 둔 시간 동안 잠금이 풀립니다.

**미리 설정하기**

1. **긴급 해제**를 엽니다.
2. **긴급 해제 유지 시간**을 1~60분 사이로 정합니다.
3. **긴급 해제 문장 수**를 0~99개 사이로 정합니다.
4. **설정 저장**을 누릅니다.

처음 설정은 **10분, 3문장**입니다. 문장 수를 0개로 설정하면 문장을 입력하지 않고 해제할 수 있습니다.

**잠금 중 사용하기**

1. 잠금 화면에서 **긴급 해제**를 누릅니다.
2. 화면에 나온 문장을 줄바꿈까지 그대로 입력합니다. 붙여넣기는 사용할 수 없습니다.
3. **긴급 해제**를 누릅니다.

정해 둔 시간이 끝났을 때 여전히 사용 금지 시간이라면 다시 잠깁니다. 그때 적용 중인 사용 예약이 있다면 예약에 따라 계속 사용할 수 있습니다.

### 시간 외 사용 예약

특정 날짜에 늦게까지 컴퓨터를 써야 한다면 미리 예약할 수 있습니다. 예약한 시간 동안에는 사용 금지 시간이어도 잠기지 않습니다.

1. **시간 외 사용 예약**을 엽니다.
2. **예약 추가**를 누릅니다.
3. 날짜, 시작 시각, 종료 시각을 입력합니다. 필요하면 메모도 적습니다.
4. **등록**을 누릅니다.

예를 들어 평소 밤 11시에 잠기도록 설정했다면, 필요한 날에 **오후 11시부터 오후 11시 50분까지** 예약해 그 시간 동안 사용할 수 있습니다.

- 하나의 예약은 같은 날짜 안에서 시작하고 끝나야 합니다.
- 기존 예약과 시간이 겹치면 등록할 수 없습니다.
- 예약이 끝나면 목록에서 자동으로 삭제됩니다. 이후에도 사용 금지 시간이라면 다시 잠깁니다.
- 예약을 바꾸려면 기존 예약을 **삭제**한 뒤 다시 등록합니다.
- 적용 중인 예약도 삭제할 수 있습니다. 사용 금지 시간에 적용 중인 예약을 삭제하면 즉시 잠금이 실행됩니다. 단, 진행 중인 긴급 해제는 유지됩니다.

### 설정 변경 제한

사용 금지 시간에는 긴급 해제 설정을 바꾸거나 새 사용 예약을 등록할 수 없습니다. 긴급 해제나 예약으로 잠시 사용 중이어도 불가능합니다. 필요한 설정과 예약은 잠금 시작 전에 저장하세요.

기존 예약의 삭제는 사용 금지 시간에도 가능합니다.

### 자동 실행

설치 후에는 Windows에 로그인하면 ZARA가 자동으로 실행됩니다.

**기본 → 실행 설정**의 **잠금이 해제된 상태에서도 프로그램이 종료되면 자동으로 다시 실행**을 켜면, 평소에도 프로그램이 예기치 않게 꺼졌을 때 다시 실행됩니다. 처음에는 켜져 있으며, 사용 금지 시간에는 이 설정과 관계없이 다시 실행됩니다. 시스템 트레이에서 직접 종료할 경우에는 다시 실행되지 않습니다.

### 프로그램 종료하기

시스템 트레이에서 ZARA 아이콘을 오른쪽 클릭 후 **종료**를 선택합니다. 이렇게 종료하면 자동으로 다시 실행되지 않으며, **프로그램을 다시 켤 때까지 자동 잠금도 작동하지 않습니다**.
