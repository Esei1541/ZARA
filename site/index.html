잠금 해제

설정 실수나 원치 않는 설치로 PC가 잠겼다면 복구 파일로 잠금을 해제할 수 있습니다.

복구 파일 다운로드

PC의 잠금 해제 안내 창을 열어둔 상태에서 진행해주세요.

연결 방법

USB 메모리

  1. 복구 파일을 USB 메모리에 저장해주세요. USB 메모리를 열었을 때 바로 보이는 위치에 파일이 있어야 합니다.
  2. USB 메모리를 잠긴 PC에 연결해주세요.
  3. PC에 해제 확인 창이 나타나면 내용을 확인하고 ‘잠금 해제’를 눌러주세요.

Android

  1. 복구 파일을 휴대폰의 다운로드 폴더에 저장해주세요.
  2. 휴대폰의 잠금을 풀고 데이터 전송이 가능한 USB 케이블로 잠긴 PC에 연결해주세요.
  3. 휴대폰의 USB 연결 알림에서 ‘파일 전송’을 선택해주세요.
    파일 접근 허용을 묻는 안내가 나오면 허용해주세요.
  4. PC에 해제 확인 창이 나타나면 내용을 확인하고 ‘잠금 해제’를 눌러주세요.

iPhone

iPhone을 PC에 USB로 직접 연결하는 방식은 지원하지 않습니다.

복구 파일을 별도 USB 메모리에 옮긴 뒤 위의 USB 메모리 안내를 따라 진행해주세요.

파일이 인식되지 않나요?

  • PC의 잠금 해제 안내 창을 닫았다면 다시 열고, 새 QR 코드로 파일을 다시 받아주세요.
  • USB 메모리를 열었을 때 복구 파일이 바로 보이는지 확인해주세요.
  • 휴대폰의 다운로드 폴더에 복구 파일이 있는지 확인해주세요.
  • 휴대폰의 잠금을 풀고 USB 연결 설정이 ‘파일 전송’인지 확인해주세요.
  • 충전만 가능한 USB 케이블은 사용할 수 없습니다. 데이터 전송이 가능한 케이블로 연결해주세요.
  • 장치를 분리했다가 다시 연결해주세요.
  • 다운로드가 시작되지 않으면 ‘복구 파일 다운로드’를 다시 눌러주세요.
